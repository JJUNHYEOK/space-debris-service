# 🛰️ 우주쓰레기 분류 서비스

고등학생 AI 멘토링 프로젝트의 결과물입니다. 사진을 올리면 ① 물체의 위치를 정하고 → ② AI가 종류(위성 10종 + 우주쓰레기)를 판별하고 → ③ **학생이 직접 파이썬으로 짠 판정 규칙**이 최종 판정을 내립니다.

- 모든 처리는 브라우저 안에서 일어납니다. 올린 사진은 서버로 전송되지 않습니다.
- AI 실행: ONNX Runtime Web · 파이썬 실행: Pyodide (자세한 라이선스는 `THIRD_PARTY_NOTICES.md`)
- 학습 데이터는 컴퓨터로 만든 합성 이미지라서, 실제 우주 망원경 사진에서는 틀릴 수 있습니다.
